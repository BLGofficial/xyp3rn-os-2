## 2. The Sofia clock (apps/web/lib/clock.test.ts)
 ✓ winter: 2026-01-15T12:00:00Z → 14:00:00 GMT+02:00
 ✓ summer: 2026-07-15T12:00:00Z → 15:00:00 GMT+03:00
 ✓ the second before the spring jump: 2026-03-29T00:59:59Z → 02:59:59 GMT+02:00
 ✓ the spring jump (03:00 never happens): 2026-03-29T01:00:00Z → 04:00:00 GMT+03:00
 ✓ the autumn hour, first pass: 2026-10-25T00:30:00Z → 03:30:00 GMT+03:00
 ✓ the autumn hour, repeated: 2026-10-25T01:30:00Z → 03:30:00 GMT+02:00
 ✓ rolls the date at Sofia midnight, not UTC midnight
 ✓ gives the same answer whatever the process timezone is (America/New_York, Asia/Tokyo, UTC)
 ✓ event timestamps: 2026-09-27T15:36:57Z → 2026-09-27 18:36:57 +03:00 (every <Time> on every page)
 ✓ estimates the offset from the round trip's midpoint; keeps the lowest round trip
 ✓ claims server sync only after a successful sample, and marks it stale after ten minutes
Live in the browser: "SOFIA, BG · 18:49:46 · Server-synced" at 15:49:46Z (section 4).
