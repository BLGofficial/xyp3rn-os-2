## 0. Status of the gate (PLAN.md §5 Phase 4: "reusable findings retain their sources and cannot silently become canonical without approval")
# - Sources retained: fetch_source keeps the page text it read (research_sources.text); every agent claim carries the
#   verbatim quote behind it (research_evidence.quote), checked by the DB on insert against that text (or, for an
#   ingested document, the canonical bodies quoting it). A fabricated quote or a typographic variant is refused (23514)
#   and the specialist declines it with the reason; nothing is written. Section 2b: the fabricated claim declined.
# - Not silently canonical: accepting a finding into the Findings Library touches no canonical table
#   (xyp_decide_finding, one final decision per finding); only an accepted finding can be promoted; the Promotion Gate
#   queues the candidate for the owner (D2), and only the owner's approval writes the canonical row. Section 2c:
#   canonical counts 0/0/0 after accept and after promote, 1 prompt / 1 module / 2 history rows after approve.
# - The promoted row chains back: canonical_prompts → knowledge_candidates → research_findings →
#   research_finding_evidence → research_evidence.quote → research_sources.text (section 2d).
# - Decisions R1–R5 (F42): the OpenRouter free route; brief-level typed links (song via song_links, lineage, workflow,
#   decision); two approval tiers; one shared grounded-evidence program; runs in the background of next start (R5 on
#   Next 14.2: a detached promise, a boot sweep).
# - Shown three ways: tests/aos-04/brief-to-canonical.test.ts (with the real retrieve_context over the ingested build
#   guide), the CLIs (section 2), the browser (section 3). The brief survives xyp-vault-export/v1 into a fresh database
#   (tests/aos-04/research-export.test.ts and the gate test).
# - Written after the features, not first: the gate test and the web smoke extension, so they were never red. The DB,
#   evidence-tool, program, synthesis, run, library, export and web loader/ops tests were red first.
# - Not run live: the specialists' model call. No OPENROUTER_API_KEY is set in this environment. Section 2a runs the live
#   path up to the call (a real page fetched and kept, the run sealed error naming the missing key); the model's part is
#   the FAKE MODEL (scripted from the passages the real prompt listed), in the tests and in section 2b.
