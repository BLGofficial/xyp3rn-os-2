## 0. Status of the guide's deliverables
# - Critic agent (Critic class): x3lius-evaluation, replacing the last Phase 7 stub under the same name. It checks a
#   creative artifact version against the canonical rules in force for it and writes an x3lius.critique/v1: specific
#   violations, each tied to a rule ref, as JSON Pointer + verbatim quote + expected/found (renderable as a diff).
#   Code checks structured claims (Suno length limits, mix-report checks); the model judges prose rules; code verifies
#   every model-reported violation (rule given, path exists, quote there word for word) or drops it as unverified.
#   It never edits the artifact.
# - Revision agent (Revision class): x3lius-revision. Reads the critique, asks the model for concrete edits, applies
#   them in code all-or-nothing, and appends version N+1 naming the critique it answers (creative_artifacts.critique_id).
# - Loop control: records/x3lius/evaluation/loop.ts, `pnpm evaluate <artifactId>`. MAX_REVISIONS = 3 (user decision):
#   each round is two model calls and a call took minutes on the free route in the Phase 9 live runs, so 3 rounds +
#   the final pass is at most 7 calls; three targeted edit rounds that fail to clear the violations are unlikely to be
#   cleared by a fourth. A stall (a revision that doesn't reduce the count) escalates early. Escalation goes to the
#   human approval_queue (item_type critique_escalation) through xyp_escalate_critique, callable only by
#   xyp_evaluation_loop. A mix report is critiqued, then escalated as studio work, never revised.
# - Both proof runs (section 2): one converges, one hits the iteration guard and escalates.
# - 6C Experiment Engine unstubbed: trials are scored by the Critic, score = rules passed / rules checked; an
#   experiment whose every trial the Critic scored can validate (section 1, "6C").
# - Phase 9 take scoring stays a stub (a take is audio; an honest score needs Phase 14's TRACE analysis). New stub rows
#   say so (stub:needs-trace-analysis).
# - 5-bullet handoff for Phase 13: docs/handoffs/PHASE-12.md.
