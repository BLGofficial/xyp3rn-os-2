## Classification Legend

Every capability row is classified strictly by current factual evidence:

| Classification | Meaning |
| :--- | :--- |
| **`VERIFIED`** | Confirmed directly in official Image-Line / Cockos API documentation and/or local files inspected on this workstation (`midi.py`, `device_Fire.py`, `FL64.exe`, `VST3/` directory, OS PnP table). |
| **`EXPERIMENTAL`** | Official API mechanism exists, but end-to-end runtime behavior, parameter stability, parsing edge cases, or latency requires hands-on verification inside the installed DAW on Windows 11. |
| **`UNSUPPORTED`** | Officially absent from the target DAW's scripting/CLI/file contract, blocked by sandbox security, or prohibited by OS3 safety architecture (must return `DAW_CAPABILITY_UNSUPPORTED`, never simulated). |
| **`UNKNOWN`** | Requires missing host prerequisites (`loopMIDI`, `reaper.exe`, unlocked license introspection, or live runtime execution) before truth can be established. |
