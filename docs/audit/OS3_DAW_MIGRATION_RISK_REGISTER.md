# XYP3RN OS 3.0 + DAW Brain Risk Register

**Audit Date:** 2026-11-16  
**Scope:** Workspace, dependency, OS2-to-OS3 migration, security, UI, Audio Brain, FL Studio 2025 Producer Edition, and REAPER architectural risks.  
**Likelihood / Impact Scale:** `Low` | `Medium` | `High` | `Critical`

---

## 1. Master Risk Register

| ID | Subsystem | Risk Description | Verified Evidence / Trigger | Likelihood | Impact | Mitigation & Gate Control |
|---|---|---|---|---|---|---|

| **R-02** | Runtime / Deps | **Dual Lockfile & Toolchain Divergence:** `officialFolderofXYP3RNOS` uses `pnpm` + TS `^7.0.2` (`NodeNext`, `erasableSyntaxOnly`) on Node `v26.13.0` (`engines >=22`); `UI-xyp3rn` uses `npm` + Next `14.2.35` + TS `^5.6.3`; legacy `apps/web` uses Next `15.5.27`. | Package manifests & `DEPENDENCY_COMPATIBILITY.md`. | **Medium** | **High** | Share pure JSON/TypeScript wire contracts without forcing shared React/TS builds across repos; keep `pnpm.cmd` in backend and `npm.cmd` in `UI-xyp3rn`; test against Node >=22 strict TypeScript flags. |
| **R-03** | OS2 -> OS3 Parity | **96 Postgres-Bound Files Still Active in Monorepo:** Running legacy CLIs or `tech/trace/serve-cli.ts` (`:8787`) fails or hits stale Postgres `:5432` schemas (`apps/web/server/*`). | `rg -l "postgres|core/db"` returned 96 files across backend modules. | **High** | **Medium** | Do not call legacy Postgres CLIs in OS3 pipelines; split `test:os3` in `package.json`; keep `core/db` read-only for rollback while migrating `tech/trace` onto SQLite + VaultEngine. |
| **R-04** | FL Studio 2025 IPC | **Python Sandbox Blocks Sockets & File IPC:** FL Studio MIDI scripts run inside a sandboxed Python interpreter without `socket`, `http`, `subprocess`, or general filesystem writes. | Image-Line official MIDI Scripting API sandbox docs + `device_Fire.py` imports audit. | **Critical** | **High** | Do **not** design HTTP or socket calls inside FL MIDI scripts; use a Windows virtual MIDI loopback (`loopMIDI`) SysEx transport bridged by an OS-side Node/Python MIDI relay process. |
| **R-05** | FL Studio 2025 Adapter | **Missing Virtual MIDI Driver (`loopMIDI`):** Host currently has no `loopMIDI` or virtual MIDI loopback driver registered in `Get-PnpDevice`. | Windows PnP device inspection (`2026-11-16`). | **High** | **High** | Document `loopMIDI` installation as an explicit manual operator setup prerequisite before live FL Studio testing; ship pure-protocol unit tests with a mock MIDI transport first. |
| **R-06** | FL Studio Plugins | **Cannot Programmatically Load/Delete Plugins:** FL MIDI Scripting API lacks `addPlugin`/`addChannel`/`removePlugin` calls. | FL Studio API Stubs & MIDI Scripting docs (`VERIFIED`). | **Critical** | **High** | Design FL Studio adapter as **template-scoped & read-modify** (operates on pre-loaded channels/slots or guides user step-by-step), never assuming dynamic VST3 instantiation via MIDI scripts. |
| **R-07** | FL Studio Edition | **Producer Edition Plugin Boundaries:** Target tier (`Producer Edition`) excludes Signature/All-Plugins tools (Harmor, Gross Beat, Newtone, DirectWave Full, Vocodex). Local encrypted license plate prevents programmatic offline tier confirmation (`UNVERIFIED`). | Official Image-Line Edition matrix + encrypted HKCU registry. | **Medium** | **Medium** | Build Plugin Brain around explicit `edition` metadata + local VST3 folder scan + runtime plugin probe via FL Studio `plugins.getPluginName()`, blocking/warning on unlicensed demo plugins. |
| **R-08** | FL Studio Safety / Audio | **Unverified Parameter / Gain Blasts:** Autonomous write to FL mixer faders or compressor/limiter/EQ parameters (`plugins.setParamValue`) could push master output > `0 dBFS`, risking monitor clipping or hearing fatigue. | DAW Brain Requirement #9 (*"Never execute unverified DAW actions"*). | **Medium** | **Critical** | Enforce strict bounded parameter ranges, max-delta per step (`clamp`), mandatory pre-write `dry-run` diff + snapshot, mixer mute/headroom safety check, and explicit human approval for structural/high-gain actions. |
| **R-09** | `.flp` Parsing & Writes | **Binary `.flp` Format Mutation Corruption:** FL Studio 2025/2026 `.flp` files contain undocumented Image-Line binary chunks; external writes can corrupt project files silently. | Audio/FL file research + Rule 5 (*"Never overwrite canonical data silently"*). | **High** | **Critical** | **Forbid binary `.flp` writes** from external Node/Python scripts. Allow strictly read-only `.flp` inspection with SHA-256 checksum guards & backup snapshots; modify live sessions only via official FL Studio APIs or user saves. |
| **R-10** | FL CLI Export | **CLI Stem Export Limitation:** `FL64.exe /R` renders Master mix cleanly, but has no CLI flag to force `"Split mixer tracks"` stems headlessly. | Official Image-Line CLI flags audit. | **High** | **Medium** | Use `/R /Ewav` strictly for master bounce capture; support stem intake cleanly via user-saved template exports or watched render drop folder without brittle GUI keystroke macros. |
| **R-11** | REAPER Validation | **REAPER Binary Not Installed on Host:** Zero `reaper.exe` / `reaper.ini` exists locally (only orphaned icon `.png`s under `C:\Program Files\REAPER (x64)`). | Windows filesystem & Uninstall registry check (`2026-11-16`). | **Medium** | **Medium** | Implement REAPER adapter strictly against official `.rpp` text format + OSC/ReaScript contracts with deterministic unit fixtures; defer live host verification until operator installs REAPER. |
| **R-12** | Vault Concurrency | **Obsidian Lock / Windows `EBUSY` & Desktop `.git`:** Obsidian open on `XYP3RN-Suno-KB-v1.2-Brain` can trigger `EBUSY`; `C:\Users\blago\Desktop\.git` wraps the Vault directory. | Desktop `.git` check + `DEPENDENCY_COMPATIBILITY.md`. | **Medium** | **Medium** | Route every Vault mutation solely through `VaultEngine` (`writeFileAtomic` backoff + CAS + Promotion Gate) and ensure any Git/backup commands pass explicit `-C <repoRoot>` never hitting Desktop root. |
| **R-13** | Localhost Auth & UI | **Opt-In Token + WebGL/PNA Differences:** `XYP_GATEWAY_TOKEN` is opt-in (unset by default); `UI-xyp3rn` accesses `127.0.0.1:8077` from `:3000` (or `localhost:3000`), and `/chart` fails blank offline without a seed graph fallback. | `core/gateway/server.ts`, `UI-xyp3rn/lib/gateway.ts`, `KnowledgeGraphView.tsx`. | **Low** | **Medium** | Document token setup cleanly for multi-process DAW bridges; preserve strict `127.0.0.1` binding + Host/Origin allowlist (`Rule 8`); add seed graph fallback to `/chart` in future UI phase. |
