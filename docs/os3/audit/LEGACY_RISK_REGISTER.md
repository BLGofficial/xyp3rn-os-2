# XYP3RN OS 3.0 — Legacy Risk Register & Mitigation Matrix

Every risk below is backed by direct code and filesystem evidence discovered during the Phase 1 Engineering Audit.

| ID | Severity | Risk Description & Evidence | Affected Files / Paths | Mitigation & OS 3.0 Control |
|---|---|---|---|---|

If that OpenRouter key is still active, it is exposed in filesystem metadata. | `E:\FileHistory\blago\XYP3RN\Data\C\Users\blago\Desktop\sk-or-v1-[REDACTED]` | **Immediate Action Recommended:** Revoke/rotate that OpenRouter API key in the OpenRouter dashboard and delete the filename from Desktop and FileHistory. Never store keys in filenames or Vault notes. |
| **R-02** | **HIGH** | **FileHistory Backup Directory Confusion:** The initial IDE workspace opened in `e:\FileHistory\blago\XYP3RN\Data\C\Users\blago\Desktop\oss2\xyp3rn-os-2-aos04`, where Windows FileHistory appends ` (2026_09_27 19_30_24 UTC)` to every filename. Editing or running builds there fails or mutates backup snapshots. | `E:\FileHistory\...` vs `C:\Users\blago\Desktop\oss2\officialFolderofXYP3RNOS` | Pin all engineering work and scripts to the live checkouts: `C:\Users\blago\Desktop\oss2\officialFolderofXYP3RNOS` and `C:\Users\blago\Desktop\building-agentic-systems\XYP3RNOS\UI-xyp3rn`. |
| **R-03** | **HIGH** | **Three Divergent Local Checkouts of `xyp3rn-os-2`:** The host has `xyp3rn-os-2` (`feat/p01-shell`), `xyp3rn-os-2-aos04` (`claude/aos-04`), and `officialFolderofXYP3RNOS` (`feat/ops-surface-v2` with untracked `New folder/`, root `.tsx` prototypes, and `captures/`). | `C:\Users\blago\Desktop\oss2\*` | `officialFolderofXYP3RNOS` is designated as the canonical OS 3.0 source checkout. Untracked prototype directories (`New folder/`) are excluded from the OS 3.0 runtime. |
| **R-04** | **HIGH** | **19,632 Root-Level Notes in `XYP3RN-Suno-KB-v1.2-Brain`:** The canonical Suno KB Vault stores 19,632 `.md` files directly in the Vault root rather than inside `01_CORE`..`06_GOVERNANCE`. Naive per-file autocommit indexing or unthrottled chokidar watchers will stall startup or lock SQLite. | `C:\Users\blago\Desktop\XYP3RN-Suno-KB-v1.2-Brain\*.md`, `core/vault-engine/engine.ts` | **Mitigated in `VaultEngine`:** Root KB notes are classified as `sector: 'ROOT_KB'` (`isCanonical: true`, read-only for agents), indexed in batches of `400` inside `BEGIN IMMEDIATE ... COMMIT` WAL transactions, and skipped via `mtime + byte_size` fast-path on incremental scans (`2.2s` for 20,189 files). |
| **R-05** | **HIGH** | **77 Stub Nodes in `UI-xyp3rn/data/map.ts` vs Live Vault Content:** `UI-xyp3rn/data/map.ts` marks 77 of its 137 constellation nodes as `stub: true` (`// STUB: not defined in the source spec.`), and `lib/__tests__/data.test.ts` asserts that exact count (`expect(stubs).toHaveLength(77)`). Mutating `data/map.ts` directly breaks `data.test.ts` and `layout.test.ts.snap`. | `UI-xyp3rn/data/map.ts`, `UI-xyp3rn/lib/__tests__/data.test.ts`, `UI-xyp3rn/lib/__tests__/layout.test.ts` | Keep `data/map.ts` deterministic so all 85 UI unit/snapshot tests pass, while hydrating live Vault notes dynamically through `127.0.0.1:8077` (`/api/vault/note`, `/api/vault/search`, `/api/jarvis`). |
| **R-06** | **MEDIUM** | **YAML Numeric Tag Drop & Template Flow-Mapping Warnings:** `knowledge/obsidian/parser.ts` originally filtered tags with `typeof t === 'string'`, silently dropping numeric tags like `808` (`tags: [drill, 808]`), and emitted Node warnings on Obsidian templates containing `{{title}}`. | `knowledge/obsidian/parser.ts` | **Fixed & Verified:** `tagList()` now accepts `string | number` and `parseYaml()` runs with `{ logLevel: 'silent' }` (`tests/os3-phase1/vault-engine.test.ts`). |
| **R-07** | **MEDIUM** | **Browser Private Network Access (PNA) & CORS Blocking between `:3000` and `:8077`:** Modern Chromium browsers block `fetch('http://127.0.0.1:8077/...')` from `http://localhost:3000` unless `Access-Control-Allow-Private-Network: true` and `Access-Control-Allow-Origin` are returned on preflight `OPTIONS` and responses. | `core/gateway/server.ts`, `UI-xyp3rn/lib/gateway.ts` | **Fixed & Verified:** `core/gateway/server.ts` enforces localhost/127.0.0.1 origin allowlisting and responds with `Access-Control-Allow-Private-Network: true` and `Vary: Origin`. |
| **R-08** | **MEDIUM** | **PostgreSQL Role-Based Security vs Single-Process Local SQLite:** Legacy OS 2.0 relied on 18 PostgreSQL `NOLOGIN` roles (`SET LOCAL ROLE xyp_*`) and RLS policies to enforce append-only and single-writer invariants. SQLite does not have `SET LOCAL ROLE`. | `supabase/migrations/*.sql` vs `core/sqlite/schema.ts`, `core/vault-engine/engine.ts` | **Mitigated:** OS 3.0 enforces immutability and seal invariants via SQLite `BEFORE UPDATE` and `BEFORE DELETE` `RAISE(ABORT, ...)` triggers (`trg_agent_runs_seal`, `trg_jobs_seal`, `trg_runtime_events_no_update`, `trg_pending_approvals_seal`) plus capability checks in `ToolRegistry.authorize()` and canonical path guards in `VaultEngine`. |
| **R-09** | **LOW** | **PowerShell `.ps1` Wrapper Execution Block on Windows:** Calling `pnpm` or `npx` in PowerShell invokes `pnpm.ps1` / `npx.ps1`, failing when Windows ExecutionPolicy blocks scripts. | Windows shell commands & `scripts/*.ps1` | Always invoke `pnpm.cmd`, `npx.cmd`, `npm.cmd`, or `node` directly. |
| **R-10** | **LOW** | **Unverified Live External Providers without Keys:** Anthropic, Groq, Suno reseller (`sunoapi`), and Whisper STT server (`127.0.0.1:9000`) are not configured with live credentials/processes on this machine. | `.env.example`, `core/llm/providers.ts`, `apps/web/server/speech.ts` | Clearly report these integrations as **unverified live** (verified against deterministic fakes/fixtures only); never fabricate live external API telemetry. |
