# OS3 + DAW Brain Unresolved Risk Register (Phase 23)

This register records remaining security, dependency, and operational risks that cannot be safely eliminated by code guards alone or require operator/environment remediation or breaking upstream upgrades.

| Risk ID | Severity | Domain | Description & Observed Evidence | Current Mitigations | Recommended Remediation & Owner |
|---|---|---|---|---|---|
| **RISK-01** | **High** | Authentication (Local Dev Mode) | `core/gateway/cli.ts` and `scripts/start-os3.ps1` start `xyp3rn-os3-gateway` with `authToken` disabled unless `XYP_GATEWAY_TOKEN` is set in env; any local process / localhost origin can invoke gateway APIs when unauthenticated. | Strict `127.0.0.1` binding + Host/Origin/Referer allowlist (`isAllowedGatewayOrigin`) + F35/D2 human-identity checks + fail-closed `XYP_REQUIRE_AUTH=1` startup option. | Provision a generated per-user `XYP_GATEWAY_TOKEN` in `.env.local` and set `XYP_REQUIRE_AUTH=1` for shared or non-dev workstations (UI client passes Bearer/`X-XYP-Token`). |
| **RISK-02** | **High** | Dependency Vulnerabilities (`UI-xyp3rn` & `apps/web`) | `npm audit` in `UI-xyp3rn` flags 11 advisories (`1 critical`, `4 high`, `6 moderate`) in `next@14.2.35`, `eslint-config-next`, `glob`, and `postcss`. `pnpm audit` in OS3 flags `next@15.5.27` (`GHSA-2464-fhr4-w9xw` critical Image Optimization SVG RCE, `GHSA-p3m5-59mp-jv5r` high, plus moderate advisories). | Gateway binds `127.0.0.1` only (not public Internet); UI avoids untrusted remote SVG Image Optimization loaders and Server Actions on untrusted input. | Schedule coordinated Next.js major/minor upgrade (`apps/web` -> Next `>=15.5.29` or `16.x`; `UI-xyp3rn` -> `next@16.4.6` & `eslint-config-next@16.4.6`) with full E2E verification. |
| **RISK-03** | **High** | Dependency Vulnerability (`sharp` via `@huggingface/transformers`) | `pnpm audit` reports `GHSA-wq5f-xc86-pv6w` (high, `sharp@0.35.4 <0.35.5` upstream `librsvg` CVE-2026-96889 when decoding untrusted SVGs on glibc Linux). | Vault & Audio pipelines never feed untrusted SVG images into `sharp`; primary deployment target is local Windows 11 workstation. | Add pnpm override for `sharp >=0.35.5` once `@huggingface/transformers` native prebuilds align, and avoid SVG inputs in local embedding workers. |
| **RISK-04** | **Medium** | Dev Dependency Advisories (`vite`, `@vitest/mocker`) | `pnpm audit` reports dev-only advisories in `vitest > vite@8.3.0` (`GHSA-587h-7wmj-h5pm` high, plus moderate/low) and `@vitest/mocker` (`<5.0.3`). | Strictly `devDependencies`; never shipped or executed in runtime daemon (`core/gateway/cli.ts`). | Bump `vitest` / `vite` to patched toolchain release (`vite >=8.3.3`, `@vitest/mocker >=5.0.3`) in next dev-tooling maintenance window. |
| **RISK-05** | **Medium** | DAW IPC Channel (`xyp3rn_reaper_bridge.lua` / FL MIDI) | Loopback HTTP REAPER bridge reference script (`xyp3rn_reaper_bridge.lua`) and WinMM MIDI (`loopMIDI`) lack OS-level mutually authenticated TLS because ReaScript Lua environments lack native TLS servers cleanly. | Loopback-only host enforcement (`127.0.0.1`/`localhost`/`[::1]`), response cap (`2 MiB`), optional `X-XYP-Bridge-Token` header on HTTP transport, read-only default sessions, and human approval gate. | Configure shared `bridgeToken` in both REAPER bridge configuration and `HttpReaperBridgeTransport` when running active REAPER RPC bridge listeners. |
| **RISK-06** | **Medium** | Approval Actor Spoofing on Unauthenticated Localhost | When `XYP_GATEWAY_TOKEN` is unset, human vs agent identity discrimination (`AGENT_OR_SYSTEM_ACTOR_RE`) relies on honest `approver` strings on localhost; a malicious local process could supply a human-shaped string such as `'operator-bypass'`. | Blocks all known agent names/prefixes and self-approval matching proposer identity; enforces audit logs & SQLite F35 checks. | Enable `XYP_GATEWAY_TOKEN` + `XYP_REQUIRE_AUTH=1`, and integrate OS user/session binding for high-risk `human_strong` DAW approvals in a future phase. |
| **RISK-07** | **Low** | FL Studio Producer Edition Live RAM Audio Ceiling | FL Studio Producer Edition does not expose direct mixer PCM buffers via Python Controller Scripting; internal audio taps remain unsupported without external WAV export. | Explicit fail-closed refusal (`assertNoUnsupportedDawAudioTap` / `DAW_CAPABILITY_UNSUPPORTED`); never fabricates live waveform telemetry. | Documented permanent host platform limitation; workflow uses exported WAV or external TRACE analysis. |
| **RISK-08** | **Low** | In-Memory DAW Gateway Staged State Across Restarts | `DawGatewayController.#preparedByApprovalId` and `DawCommandGateway.#consumedApprovalIds` reside in gateway process memory alongside durable SQLite `approvals` / `daw_commands`. | SQLite `approvals` (`status = 'approved'` sealing) & `daw_commands` persist across restarts; pending staged diffs cleanly fail-safe if gateway restarts (`404` / requires fresh `prepare`). | Hydrate consumed-approval / receipt indexes from `daw_commands.approval_id` on startup if persistent approval replay tracking across restarts is required. |
