## Part 1 — OS2 to OS3 Capability Parity Matrix

Every retained or evaluated OS2 capability is classified strictly using one of the five canonical statuses:
- **`PARITY VERIFIED`**: Implemented in OS3 (`VaultEngine` + `node:sqlite`), verified by automated tests with zero Postgres runtime dependency.
- **`PARTIAL PARITY`**: Core OS3 engine and Vault/SQLite implementation verified, while legacy CLI entry points or pre-OS3 external Vault files remain unmigrated/dual-stack.
- **`NOT MIGRATED`**: Legacy OS2 capability intentionally left on legacy stack or pending migration.
- **`INTENTIONALLY RETIRED`**: Replaced by OS3 local-first architecture.
- **`BLOCKED`**: Gated by external prerequisites or explicit Owner approval.
