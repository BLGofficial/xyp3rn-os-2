# Phase 16A — Reference decomposition

Reference: `interface.png`. Replacement specification: the user-supplied September 25 Phase 16A–16L text. Repository at discovery had no Next.js application, CSS, component library or graph renderer. Phase 12–13 existed on `claude/phase-13` and were brought into this checkout before Phase 14–15.

The composition is a full-height dark command center: compact top identity/navigation/search; left system map, domain filters and run-state summary; dominant center radial graph; right status, timestamped activity and geographic empty state; bottom five infrastructure inspectors. Core is north, Knowledge northeast, Governance southeast, Records south, Tech southwest and Research northwest. Records contains a nested X3LIUS module panel.

The image uses black/navy backgrounds, thin beveled gold/cyan frames, condensed uppercase headings, tracked monospace microcopy, concentric orbital geometry and controlled node bloom. The hub is gold. Domain colors must come from `core/contracts/taxonomy.ts`; its accepted colors differ from the illustration and remain authoritative. No image texture or screenshot is used as the page background. Stars and orbit guides are decorative geometry and do not represent runtime entities.

Typography hierarchy: identity, domain heading, rail heading, entity label, source microcopy. Panels remain compact; satellites are bounded before overflow becomes a selectable list. Graph controls keep visible keyboard focus and reduced-motion support. Desktop composition takes priority; rails become drawers on narrower viewports.
