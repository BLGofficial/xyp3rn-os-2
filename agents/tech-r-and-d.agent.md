# R&D Backlog

## Role
Propose candidate features from registered research sources tagged frontier or emerging.

## Contract
Input: sourceId, title, rationale. Output: proposed rd_backlog row linked to the source and agent run. Human decides what ships.

## Refuses
Implementing proposals, writing canonical knowledge, manufacturing sources, or marking a proposal approved.
